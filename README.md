# Ashutosh — editorial portfolio

A static site containing four SAL article links, four YouTube links, your Financial Times letter, and your portrait.

## Preview locally

Open `index.html` in a browser. It should work without a local server. The article and YouTube images require an internet connection. The FT letter and portrait are included in the folder.

## Publish free with GitHub Pages

1. Create a GitHub account at https://github.com (or sign in).
2. Create a **public** repository named `ashutosh-portfolio` (or `YOURUSERNAME.github.io` for a shorter URL).
3. On the repository's **Code** page choose **Add file → Upload files**.
4. Upload **all the files inside this folder** (not the ZIP or containing folder): `index.html`, `styles.css`, `script.js`, `content.js`, `ashutosh-portrait.png`, `ft-letter.png`, and `README.md`.
5. Click **Commit changes**.
6. Open **Settings → Pages**, under **Build and deployment** select **Deploy from a branch**, then branch **main** and folder **/(root)**. Save.
7. The site will be published at `https://YOURUSERNAME.github.io/ashutosh-portfolio/` (or `https://YOURUSERNAME.github.io/` if you used the user-site repository name). Publication can take several minutes.

See https://docs.github.com/en/pages/quickstart for official instructions.

## Edit the portfolio

Open `content.js`. Change text inside a `note:` value to update your personal commentary; change a `title:` to rename a video; change `id:` and `url:` together to swap videos. Click Commit changes when editing on GitHub. For the homepage intro / about text, edit `index.html`.
